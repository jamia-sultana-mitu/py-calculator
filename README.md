# 🧮 PyQt5 Calculator

A simple GUI calculator built using **Python** and **PyQt5**.
This project run a Python desktop application inside a **virtual environment (venv)**.

---

## Features

* Basic arithmetic operations (+, −, ×, ÷)
* Responsive PyQt5 interface
* Clean and minimal code structure

---

## Requirements

* Python **3.8+**
* `pip` (Python package manager)

All required Python packages are listed in **`requirements.txt`**.

---

## Setup and Run

### 1. Clone the Repository

```bash
git clone https://github.com/<your-username>/pyqt-calculator.git
cd pyqt-calculator
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

### 3. Activate the Virtual Environment

**Windows (PowerShell):**

```bash
venv\Scripts\Activate.ps1
```

**macOS / Linux:**

```bash
source venv/bin/activate
```

### 4. Upgrade pip and Build Tools

Before installing PyQt5, make sure your environment tools are updated:

```bash
pip install --upgrade pip setuptools wheel sip
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python calculator.py
```

A calculator window should appear — you’re ready to go 🎉
